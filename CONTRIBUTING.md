# Contribuír / Contribuir

Obrigado polo interese en **Pista Aberta**.

1. Abre un issue ou contacta co mantedor antes de cambios grandes.
2. Mantén a licenza **EUPL-1.2** e dependencias con licenza libre (MIT, Apache-2.0, BSD, ISC, LGPL, MPL).
3. Interface en **galego por defecto** + castelán (`react-i18next`); ningún texto fixo no código.
4. Accesibilidade WCAG 2.1 AA: HTML semántico, teclado, contraste, selector Aa na cabeceira.
5. Antes de pedir revisión: `npm run typecheck`, `npm test` e unha proba local con `docker compose up`.

## Acceso en desenvolvemento

Con `PA_DEMO=1` hai un IdP SAML de proba que simula Cl@ve, o acceso por código de correo (os correos quedan en Mailpit) e certificados de proba en `deploy/demo-ca/`.
