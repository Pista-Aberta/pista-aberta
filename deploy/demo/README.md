# Demo propia

Esta carpeta non leva contas nin concellos reais.

1. Copia `deploy/demo-users.example.json` a `deploy/demo/demo-users.json` e edita persoas inventadas do «Concello de Exemplo».
2. Opcional: define un `demo-setup.json` coa mesma forma que use a túa instancia.
3. Pon `DEMO_USERS_FILE` / `DEMO_SETUP_FILE` no `.env` e arranca con `PA_DEMO=1`.

Os nomes e NIF da demo **non** van no repositorio público.
